# Data Cleaning, Quality Remediation &amp; Preprocessing Project

\# 🚢 Data Cleaning, Quality Remediation & Feature Preprocessing Pipeline An end-to-end data hygiene and preprocessing framework applied to the \*\*Titanic Benchmark Dataset\*\*. 

This repository documents the transformation of a raw, uncleaned dataset (891 rows × 12 features) into a fully optimized, normalized, 23-feature model-ready matrix.
